# log/

This folder is auto-generated by `colcon` and contains a timestamped record of every build run. **Do not edit files here manually.**

## Structure

Each subfolder is named after the date and time of the build that produced it:

```
log/
├── build_2026-02-26_14-15-55/
├── build_2026-02-26_16-15-12/
├── build_2026-02-26_16-15-58/
├── build_2026-03-05_20-00-42/
│   └── ...
└── build_YYYY-MM-DD_HH-MM-SS/
```

Each timestamped folder contains per-package logs for that build session, including stdout, stderr, and colcon's own internal output. The most recent folder corresponds to your last `colcon build` run.

## Clearing old logs

Logs accumulate over time. To delete them all and start fresh:

```bash
rm -rf log/
```

They will be recreated automatically on the next build.
