# build/

This folder is auto-generated by `colcon` when you build the workspace. Do not edit files here manually - they are overwritten on every build.

## Contents

| Folder / File | Description |
|---|---|
| `iwr6843aop_pub/` | Build artifacts for the low-level sensor publisher - handles UART communication with the IWR6843AOP and publishes raw point cloud data |
| `object_detection/` | Build artifacts for the object detection and cluster mapping package |
| `ti_ros2_driver/` | Build artifacts for the TI ROS 2 driver - manages sensor configuration and the data pipeline |
| `.built_by` | Generated by colcon to record the build tool version |
| `COLCON_IGNORE` | Tells colcon to skip this folder when searching for packages to build |

## Rebuilding

From the workspace root:

```bash
colcon build --symlink-install
source install/setup.bash
```

To rebuild a single package:

```bash
colcon build --symlink-install --packages-select <package_name>
# e.g.
colcon build --symlink-install --packages-select object_detection
```

To clean and rebuild from scratch:

```bash
rm -rf build/ install/ log/
colcon build --symlink-install
source install/setup.bash
```
