# install/

This folder is auto-generated by `colcon` after a successful build. It contains the installed, ready-to-use versions of all packages in the workspace. **Do not edit files here manually.**

To make the packages available in your shell, source one of the setup scripts below before running any ROS 2 commands.

## Sourcing the workspace

Pick the script that matches your shell:

```bash
# Bash (most common)
source install/setup.bash

# Zsh
source install/setup.zsh

# sh
source install/setup.sh

# PowerShell (Windows)
./install/setup.ps1
```

> Run this from the **workspace root**, not from inside the `install/` folder.

## Contents

### Package folders

| Folder | Description |
|---|---|
| `backward_ros/` | ROS 2 dependency for improved crash stack traces |
| `iwr6843aop_pub/` | Installed low-level sensor publisher - UART communication and raw point cloud output |
| `object_detection/` | Installed object detection and cluster mapping package |
| `ti_ros2_driver/` | Installed TI ROS 2 driver - sensor configuration and data pipeline |

### Setup scripts

| File | Shell |
|---|---|
| `setup.bash` / `local_setup.bash` | Bash |
| `setup.zsh` / `local_setup.zsh` | Zsh |
| `setup.sh` / `local_setup.sh` | POSIX sh |
| `setup.ps1` / `local_setup.ps1` | PowerShell |

`setup.*` sources both this workspace and any parent ROS 2 underlay (e.g. `/opt/ros/humble`).  
`local_setup.*` sources only this workspace - use this if you manage underlays yourself.

### Other files

| File | Description |
|---|---|
| `.colcon_install_layout` | Records the install layout used by colcon (merged or isolated) |
| `COLCON_IGNORE` | Tells colcon to skip this folder when searching for packages |
| `_local_setup_util_ps1.py` / `_local_setup_util_sh.py` | Internal Python helpers used by the setup scripts |

## Reinstalling

To regenerate this folder from scratch:

```bash
rm -rf build/ install/ log/
colcon build --symlink-install
source install/setup.bash
```
